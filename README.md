# GharBijli Captain (Electrician Partner App)

Official native Android application for GharBijli Electricians and Technicians in Bhilai & Durg (Chhattisgarh).

## Features
- **Real-Time Booking Broadcast**: Live bookings from GharBijli customers broadcast instantly to online electricians.
- **WhatsApp-Style Incoming Call Alert**: High-priority full-screen incoming booking call overlay with persistent ringtone and vibration.
- **Exact Alarm & Background Sync**: Instant wake-up on new bookings even when app is closed or phone is locked.
- **Commission & Earnings Ledger**: Real-time breakdown of cash collected, electrician earnings, and platform commissions.
- **Dynamic Cloud Auth**: 100% backend-authenticated via MongoDB Atlas with Phone + Security PIN.

## Tech Stack
- Kotlin + Jetpack Compose
- Retrofit 2 + OkHttp 4
- Material 3 Design
- Target SDK: 35 (Android 15)
- Min SDK: 26 (Android 8.0)
